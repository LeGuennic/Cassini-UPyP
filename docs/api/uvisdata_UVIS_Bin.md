# UVIS_Bin

Container class holding the result of a pixel binning operation.
UVIS_Bin relies on the ``list_ndarray`` structure generated by the {py:func}`cassini_upyp.uvisutils.list_ndarray` function, which is used to store the indices of the pixels that belong to each bin.
